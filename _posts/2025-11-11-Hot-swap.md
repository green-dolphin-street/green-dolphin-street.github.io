* Hot-swapping in a data center allows engineers to add or remove hardware components from a server **while the operating system (OS) is running** and actively serving users.
* **Why it's for Availability:** The primary goal is to **maximize uptime (availability)** by eliminating the need for a reboot during maintenance or repairs.
* **OS Role:** The server's OS (like Linux or Windows Server) is designed to manage these events. It handles:
    * **Hot-Add:** Detecting new hardware, loading drivers, and making it available (e.g., hot-adding CPU/RAM to a VM).
    * **Hot-Remove:** Safely stopping processes using a device, flushing data caches (for drives), and releasing resources before removal.
* **Key Examples:**
    * **Drives:** Pulling a failed drive from a **RAID** array and inserting a new one. The OS (or RAID controller) automatically starts rebuilding the data.
    * **Power Supplies (PSUs):** Replacing a failed redundant power supply. The server continues running on its other PSUs.
    * **Fans:** Swapping a broken fan module before the server overheats.
    * **Advanced (OS-Level):** Using "Live Migration" to move an entire running VM (OS and all) to different physical hardware for maintenance.
