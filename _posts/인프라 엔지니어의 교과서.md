## Chapter 2: Server
### 서버의 종류
- 형태에 따른 분류
    1. Tower 형
    2. Rack mount 형
       - 랙 내부에 서버를 설치하는 슬롯은 19 인치가 표준
       - 서버의 사이즈 (두께) 단위: 1U, 2U, ... (1U=1.75인치 $\simeq$ 44.45mm)
       - 뒤에 나오는 Entry 급은 1U, 그 이상은 더 두꺼움

- 사양/수준에 따른 분류
    1. Entry
       - 주로 web server, app server용
       - 서버당 1-2 CPU (서버용 메인보드는 일반 컴 메인보드랑 달리 CPU 소켓이 2개 이상도 있을수도 있는 거임)
    2. Mid-range
        - 주로 DB 서버, backbone 업무 시스템용
        - 서버당 CPU 약 4개
    3. High-end
        - 얘도 주로 DB 서버, backbone 업무 시스템용
        - HPC급의 용도면 수 십 CPU socket이 있을 수 있음
          - 보드 한 장이 아니라, 여러 모듈을 backplane/interconnect fabric으로 연결해 scaling

- 기타 서버의 성격에 따른 분류 용어
  - IA (inter architecture) 서버
  - Enterprise 서버

### Scale-up vs scale-out
- Scale-up: 각 서버에 부품을 추가해서 성능 향상
- Scale-out: 더 많은 서버를 연결해서 성능 향상

### 서버의 주요 컴포넌트들 1. CPU
- CPU의 성능
    - 동작 주파수를 올리며 성능을 올려왔으나
    - Power wall 등을 비롯한 이슈 있음
    - 따라서 multi-core, multi-thread 등의 테크닉이 발전
- Intel의 CPU 관련 기술 용어
  - Hyper-threading: CPU의 한 물리 코어를 두 개의 논리 코어처럼 동작시켜, 동시에 더 많은 스레드를 처리할 수 있게 하는 기술
  - Turbo Boost: CPU의 부하 상황에 따라 클럭 속도를 잠깐잠깐만 끌어올려 성능을 높이는 기술

### 서버의 주요 컴포넌트들 2. Memory
- 메모리 용어
  - ECC (error correction code) 메모리
    - Parity bit 8개를 이용해 오류를 정정하는 기능이 있는 메모리
    - 오류 발생시 (1) ECC 기능으로 바로 잡고 (2) 오류 났다는 경고를 사람한테 날리고 (3) 담당자는 대처를 하는 것
  - Channel
    - CPU의 메모리 컨트롤러와 메모리 슬롯 (DIMM) 사이의 채널을 지칭
    - 메인보드에 따라 여러 메모리 채널을 지원할 수 있음
      - Dual channel, quad channel 등으로 명명
      - 채널 수만큼 해당 CPU $\leftrightarrow$ 메모리 대역폭이 뻥튀기
    - 여러 CPU가 각각 다중 채널을 가지고 있으면, 각 CPU의 메모리 연결 구성을 통일해야 함
    - Rank
        - DIMM 안에서 CPU가 한 번에 접근할 수 있는 메모리 블록 단위?
        - e.g. dual rank: 하나의 DIMM 안에 두 개의 이런 블록이 있어서, 모듈 하나가 마치 두 개처럼 동작
    - DIMM (dual in-line memory module)
      - UDIMM
      - RDIMM
      - LRDIMM
