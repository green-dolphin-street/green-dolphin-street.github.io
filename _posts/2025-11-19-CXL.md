* Compute Express Link (CXL) is an open industry-standard interconnect that enables high-speed, low-latency communication between the CPU and workloads (accelerators, memory).
* **Physical Layer:** Built upon the **PCIe Gen 5.0 and 6.0** physical infrastructure (uses the same slots and wires).
* **The "Secret Sauce":** Unlike standard PCIe, CXL maintains **Cache Coherency**.
    * The CPU and the Device share a single memory address space.
    * Changes made by one are instantly visible to the other without software drivers manually copying data.
* **Primary Goal:** To break the "Memory Wall" in data centers, allowing servers to access more RAM than the motherboard physically holds.

### CXL Device Types
CXL categorizes hardware into three specific types based on how they utilize memory:

* **Type 1: Caching Devices (Accelerators without Memory)**
    * **Examples:** SmartNICs, Atomic Accelerators.
    * **Function:** The device has no local memory; it uses CXL to reach into the **Host CPU’s memory** to process data efficiently.
    * **Use Case:** Processing network packets directly in the CPU cache.

* **Type 2: Accelerators with Memory (Dense Compute)**
    * **Examples:** GPUs, FPGAs, ASICs.
    * **Function:** The device has its own high-speed memory (HBM/DDR) but shares it with the Host CPU.
    * **Coherency:** The CPU can access the GPU's VRAM, and the GPU can access the System RAM seamlessly.

* **Type 3: Memory Expanders (Buffers)**
    * **Examples:** CXL Memory Cards, Memory Pooling Appliances.
    * **Function:** Devices that provide *only* memory capacity and bandwidth.
    * **Use Case:** Plugging a 512GB RAM card into a PCIe slot to double a server's memory capacity without buying a larger CPU.

### CXL vs. RDMA: Critical Differences
While both technologies allow a system to access data "outside" itself, they function at different layers.

* **Protocol Level**
    * **CXL:** A **Memory Protocol**. Uses CPU instructions (`Load`/`Store`). The CPU treats CXL devices as local RAM sticks.
    * **RDMA:** A **Network Protocol**. Uses `Send`/`Receive` or `Write` verbs. Requires a Network Interface Card (NIC) to packetize data.

* **Latency & Speed**
    * **CXL:** Nanosecond scale (~170–300ns). Designed for near-native memory speeds.
    * **RDMA:** Microsecond scale (~1–5µs). Fast, but orders of magnitude slower than CXL due to network traversal.

* **Distance & Scale**
    * **CXL:** **Short Reach.** Designed for inside the server chassis or within a single rack (via CXL switching).
    * **RDMA:** **Long Reach.** Designed to connect thousands of servers across a warehouse-scale data center.

* **Cache Coherency**
    * **CXL:** **Hardware Coherent.** If the CPU updates a data bit, the CXL device knows instantly (and vice versa).
    * **RDMA:** **Not Coherent.** Software must manage data versions; if Node A writes to memory, Node B doesn't know until it explicitly checks or receives a message.
